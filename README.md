## 🧩 Como o GTA VC funciona com WebAssembly?

**WebAssembly (WASM)** é um formato de instruções binárias projetado para executar código com eficiência e segurança dentro do ambiente oferecido pelo navegador. Em jogos portados de engines nativas, partes do código podem ser compiladas para WebAssembly, enquanto a página web oferece carregamento, entrada por teclado e mouse, áudio, armazenamento e renderização por APIs compatíveis.

Isso permite acessar jogos pelo navegador sem instalar um executável nativo. Ainda assim, **WebAssembly não garante, por si só, FPS elevado ou compatibilidade universal**: resultados dependem da implementação, das APIs utilizadas e do computador.

### Tecnologias

- **WebAssembly (WASM)** — execução de código compilado no navegador.
- **HTML, CSS e JavaScript** — interface e integração da página, quando usados no port.
- **WebGL / outras APIs gráficas** — renderização, conforme a implementação específica.
